NTU PROJECT · 2025 – NOW

ChemRealis

Cross-platform chemistry software for teachers and students, built with Unity so the same molecules and tools work on desktop, in the browser and in VR.

  • Point Group Determination Automatically identifies a molecule's point group and animates its rotations and reflections.
  • Chirality Detection Places a molecule beside its mirror image to check whether it is chiral or achiral.
  • Vibrational Mode Analysis Animates each normal mode in 3D, showing how every atom moves.
